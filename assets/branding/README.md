# Deadlook branding

Current public assets:
- public/deadlook-eye.svg — transparent cream/green eye with real negative-space cut-outs.
- public/deadlook-wordmark.svg — DEADLOOK in outlined in-game Reaver Bold lettering.
- public/deadlook-logo.svg — standalone, self-contained horizontal lockup.

Header and footer use these same assets on every page. Do not put a background
rectangle behind the eye, or paint its counters with the page's background color.
All SVGs must work on other backgrounds. Keep the accessible Deadlook home label.

## Original artwork backup (do not overwrite)

- backup/deadlook-eye-v1.svg: byte-for-byte original eye artwork.
- backup/deadlook-header-v1.png: original rendered eye + Georgia wordmark at 2x.
- Original header wordmark CSS: Georgia, "Times New Roman", serif; 1.65rem;
  weight 900; letter-spacing .06em; cream #ffefd7. Mobile: 1.2rem.

## Typeface provenance / fan artwork

The wordmark uses outlines rendered from reaver-bold.otf in the owner's locally
installed Deadlock game. Its embedded license notice states:

"Copyright 2020 Valve Corp. All Rights Reserved. Like other Valve game content,
you may use this font to create Fan Art, as described in the Steam Subscriber
Agreement."

Only the eight outlined glyphs are included, not a redistributable font file.
Reaver is a game typeface; this is a new fan-project wordmark, not a claim that
Valve's custom Deadlock logo is unmodified text in this font.
The eye is our original game-inspired artwork. This project is unofficial and
is not endorsed by Valve. The public SVGs do not depend on external font services.
